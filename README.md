## Featured projects

### ⚙️ [Dalamud Branch Switcher](https://github.com/Sowce/dalamud-branch-switcher)

A small native desktop tool written in **Rust** for managing and switching between Dalamud branches.

Built with Rust and egui, with asynchronous network requests, JSON serialization and configuration handling.

### 🎮 [whodis](https://github.com/Sowce/whodis)

A **C# / .NET** Dalamud plugin that identifies players in Party Finder groups using locally available player data and a shared SQLite database.

The project focuses on solving the problem without requiring additional requests to the game servers.

### 📦 [Will This Be A Good Addition To My Collection](https://github.com/Sowce/WillThisBeAGoodAdditionToMyCollection)

A Dalamud plugin that analyzes loot items and provides visual indicators showing whether an item is already collected or currently present in the player's inventory.

### 🚀 DPS Meter

A **native FFXIV DPS meter written in Odin and SDL**, currently under development.

The project is focused on:

* very low CPU and memory overhead;
* high-frequency real-time updates;
* native rendering instead of a Chromium-based overlay;
* efficient combat-data processing;
* smooth, frame-rate-independent UI interpolation.

During real-world testing with 50+ players, the application remained around **18 MB RAM, 0.6% CPU and 0.6% GPU**, with CPU spikes around **1.5%**.

The project is planned to be released as open source.
